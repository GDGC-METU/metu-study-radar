# METU StudyRadar

A simple web app concept for METU students to check live occupancy and find empty desks across campus study spots.

## What's Inside
- `index.html` — Interactive prototype (open in any browser to test)
- `presentation.pdf` — 5-slide project presentation

## Key Features
- **Campus Radar Map:** Shows live crowd levels across 6 METU study spots (Green / Yellow / Red).
- **Smart Filters:** Filter by available desks, quiet zones, power outlets, and 24/7 access.
- **Check-In & Crowd Reports:** Students can check in, scan a desk QR code, or report crowd levels. Check-ins automatically expire after 90 minutes.
- **Finals Week Mode:** Simulates peak exam-week occupancy.

## How to Run
Download the files and double-click `index.html` to open it in your browser.
